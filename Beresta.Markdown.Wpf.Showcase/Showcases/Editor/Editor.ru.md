# Правка на месте

Исходник этого документа живёт в AvalonEdit. Блоки вокруг места правки остаются нарисованными, а
правимые показывают свой исходник с разметкой.

## Задачи

- [x] Нарисовать документ
- [ ] Отметить задачу щелчком
- [/] Статус задачи из готового расширения

## Сворачиваемое

<details>
<summary>Щёлкни, чтобы развернуть</summary>

Развёрнутость сворачиваемого блока пишется обратно в исходник.

</details>

> [!note]- Свёрнутая плашка
> Она тоже помнит, развёрнута ли.

## Текст

Простой текст с **жирным**, *курсивом*, ~~зачёркнутым~~, `кодом в строке` и
[ссылкой](https://github.com/porohkun/Beresta.Markdown.Wpf).

> Цитата остаётся цитатой.

```csharp
var editor = new MarkdownEditor();
```

| Режим | Что правится |
|---|---|
| Просмотр | ничего |
| Контролы | задачи и сворачиваемое |
| Блочный | блоки под курсором |
| Полный | весь исходник |
