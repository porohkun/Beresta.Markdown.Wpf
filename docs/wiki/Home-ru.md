Markdig.Wpf.Viewer — контрол WPF, который показывает Markdown родными элементами WPF: текст
разбирает [Markdig](https://github.com/xoofx/markdig), рисуют шаблоны WPF. Ни браузера, ни HTML
посередине.

![Вьюер в теме витрины](images/overview.png)

Что он умеет:

- **Один контрол в прокрутке приложения.** Вьюер создаёт только видимые блоки, поэтому длинный
  документ, страница с другим содержимым вокруг или лента сообщений чата не тормозят.
- **Текст как в документе.** Выделение идёт сквозь абзацы, списки и таблицы; копирование кладёт в
  буфер обмена разом обычный текст, Markdown и HTML.
- **Навигация.** Ссылки открываются в браузере, якоря и сноски прокручивают документ, заголовки дают
  оглавление, а любую ссылку может взять на себя приложение.
- **Свой вид.** Каждый цвет, шрифт и отступ — ключ ресурса; любому блоку можно дать свой шаблон.
- **Свой синтаксис.** Расширения превращают свои конструкции Markdown в свои виджеты.
- **Строки исходника.** Вьюер переводит строки исходника в позиции на экране и обратно: номера строк,
  синхронизация с редактором, две панели рядом.

## Витрина

В репозитории есть витрина со сценариями из этой вики: полный документ с оглавлением, свой вид,
расширения, копирование, живой предпросмотр, две панели и большой документ. Запуск из корня
репозитория:

```bash
dotnet run --project Markdig.Wpf.Viewer.Showcase
```
