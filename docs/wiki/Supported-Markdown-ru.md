[English](Supported-Markdown) | **Русский**

Вьюер разбирает текст Markdig: CommonMark и расширенный набор расширений Markdig
(`UseAdvancedExtensions()`) — таблицы, списки задач, сноски, идентификаторы заголовков, автоссылки,
атрибуты, свои контейнеры и другое. Всё, что узнал разбор, попадает на экран: конструкция без своего
вида показывается своим содержимым или исходным текстом. Молча ничего не пропадает.

## Блоки

| Markdown | На экране |
|---|---|
| `# Heading` … `###### Heading`, подчёркивание `===` или `---` | шесть уровней заголовков |
| абзац | текст с переносом слов; перенос строки в исходнике — перенос строки на экране |
| `> quote` | черта слева; внутри любые блоки |
| `- item`, `* item`, `1. item`, `7) item` | маркеры по уровню вложенности (`•`, `◦`, `▪`), номера от первого пункта |
| `- [ ] task`, `- [x] task` | флажок перед пунктом — см. [Списки задач](Task-Lists-ru) |
| ```` ```lang ```` код в ограждении | блок кода с шапкой языка — см. [Блоки кода](Code-Blocks-ru) |
| код с отступом в четыре пробела | блок кода без шапки |
| `\| a \| b \|` со строкой `\|---\|---\|` | таблица со строкой заголовка; `:---`, `:---:` и `---:` выравнивают столбцы |
| `---`, `***` | горизонтальная черта |
| `[^1]: text` | определение сноски — см. ниже |
| `:::name` … `:::` | свой контейнер: показывает содержимое; [расширение](Extensions-ru) может нарисовать его по-своему |
| HTML-блок | его исходный текст |
| `<!-- comment -->` | ничего |

## Внутри строки

| Markdown | На экране |
|---|---|
| `**bold**`, `*italic*`, `***both***` | жирность и наклон |
| `~~strike~~` | зачёркивание |
| `` `code` `` | код в рамке |
| `[text](https://example.com "title")` | ссылка; заголовок — её подсказка, см. [Ссылки и якоря](Links-and-Anchors-ru) |
| `<https://example.com>`, `www.example.com` | ссылки |
| `![alt](picture.png)` | картинка — см. [Картинки](Images-ru) |
| `[^1]` | ссылка на сноску |
| `&copy;`, `&laquo;` | знаки © и « |
| два пробела или `\` в конце строки, `<br>` | жёсткий перенос строки |

Строчный HTML: `<b>`, `<strong>`, `<i>`, `<em>`, `<s>`, `<del>`, `<strike>`, `<code>`, `<kbd>`,
`<sub>`, `<sup>`, `<a href="…" title="…">`, `<img src="…" alt="…" width="…" height="…">` и `<br>`
рисуются как их аналоги из Markdown; `<kbd>` — клавишей. Другие теги показываются текстом.

**Любой `.md`-файл**:

```markdown
Press <kbd>Ctrl</kbd>+<kbd>C</kbd> to copy. Water is H<sub>2</sub>O, the area is 5 m<sup>2</sup>.
```

## Переносы и пустые строки

Вьюер сохраняет форму исходника. Каждая строка исходника начинается на экране с новой строки: мягкий
перенос внутри абзаца рисуется переносом, а не пробелом. Каждая пустая строка между блоками
становится отступом. Документ выглядит как его текст — поэтому с исходником совпадают и
[номера строк](Line-Numbers-ru), и [две панели](Source-Lines-and-Two-Panes-ru).

## Сноски

Определение сноски остаётся там, где написано: в конец документа оно не уезжает. Щелчок по ссылке на
сноску прокручивает к определению, `↩` в определении — обратно к ссылке.

**Любой `.md`-файл**:

```markdown
The viewer is built on Markdig[^parser].

[^parser]: A fast, CommonMark-compliant Markdown parser for .NET.
```

Чтобы показывать сноски по-своему — например, подсказкой у ссылки, — их перекрывают расширением:
[Расширения → Перекрытие встроенного синтаксиса](Extensions-ru#перекрытие-встроенного-синтаксиса).

## Своя настройка разбора

`MarkdownPipeline` заменяет стандартную настройку разбора Markdig — например, чтобы выключить
синтаксис. [Расширения](Extensions-ru) вьюера добавляются поверх неё.

**`MainWindow.xaml.cs`**, в конструкторе (`using Markdig;`):

```csharp
Viewer.MarkdownPipeline = new MarkdownPipelineBuilder()
    .UsePipeTables()
    .UseTaskLists()
    .Build();
```
