[English](Accessibility) | **Русский**

Вьюер описывает документ для UI Automation — интерфейса, через который работают экранные дикторы
вроде Экранного диктора Windows и NVDA и средства тестирования, — той же структурой, что видна на
экране.

## Что получают дикторы

| На экране | Для UI Automation |
|---|---|
| вьюер | `Document` |
| абзац, ячейка таблицы | `Text` с текстом абзаца |
| заголовок | `Text` с уровнем заголовка от 1 до 6: дикторы прыгают по заголовкам |
| список, список определений, цитата, сноска | `List` или `Group` из созданного содержимого |
| плашка, сворачиваемый блок | `Group` с именем-заголовком; сворачиваемый можно развернуть и свернуть |
| ссылка | `Hyperlink`, которую можно нажать |
| ссылка на сноску и `↩` | `Hyperlink` с именем — номером сноски или `↩`; нажатие прокручивает, как щелчок |
| картинка | `Image` с именем из alt |
| задача | `CheckBox`; недоступен, пока приложение не разрешит переключать задачи |
| кнопка копирования блока кода | `Button` с именем из ключа темы `Md.CodeBlock.CopyToolTip` |

Имя самого вьюера задаёт приложение: его диктор произносит, когда фокус приходит в документ.

**Окно или пользовательский контрол**:

```xml
<mdv:MarkdownViewer Markdown="{Binding Text}" AutomationProperties.Name="Release notes" />
```

Подписи интерфейса — имя кнопки, пункты меню — по умолчанию английские; переводятся ключами темы:
[Тема → Подписи интерфейса](Theming-ru#подписи-интерфейса). Картинке лучшее имя даёт осмысленный alt:
`![Sales by month, 2025](sales.png)`.

## Клавиатура

Вьюер берёт фокус по щелчку и обрабатывает Ctrl+A, Ctrl+C и Ctrl+Shift+C. Tab ходит по ссылкам
созданных блоков, Enter открывает ссылку с фокусом. Контекстное меню открывается клавишей меню или
Shift+F10. Выделять текст стрелками нельзя.

## Ограничение: видны только созданные блоки

Вьюер создаёт контролы только для видимых блоков — см.
[Прокрутку и виртуализацию](Scrolling-and-Virtualization-ru). UI Automation видит те же созданные
блоки: текста блоков за краем в дереве автоматизации нет, пока их не прокрутят в видимое, поэтому
«читать всё» останавливается на конце созданной части. Короткий текст без прокрутки вокруг создаёт все
свои блоки и виден UI Automation целиком.

Что получает диктор, проверяют Экранным диктором или
[Accessibility Insights for Windows](https://accessibilityinsights.io/docs/windows/overview/).
