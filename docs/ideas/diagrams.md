# Идея: диаграммы

Вьюер рисует диаграммы, описанные текстом. Общая часть и два рисовальщика обходятся без чужих
.NET-библиотек и могут жить в основной библиотеке; рисовальщик mermaid без сети — пакет-спутник
`Beresta.Markdown.Wpf.Diagrams.WebView2`.

## Задача

Блок кода с языком диаграммы содержит её описание текстом:

- `mermaid` — блок-схемы, диаграммы последовательности, Ганта, классов, состояний;
- `plantuml`, `dot` (Graphviz), `d2`, `nomnoml` и другие.

GitHub, GitLab и Obsidian рисуют вместо такого блока картинку.

## Как сейчас

Блок рисуется обычным блоком кода с шапкой языка. Расширение Diagrams из стандартной настройки
разбора Markdig влияет только на HTML: заворачивает блок в разметку для JavaScript веб-страницы.
Для вьюера оно ничего не меняет.

## Почему не своими силами

Рисовальщики написаны не на .NET: mermaid — на JavaScript, ему нужен браузер; PlantUML — на Java;
Graphviz — отдельная программа на C. Годных рисовальщиков на чистом .NET нет.

## Общая часть

- Расширение `MdDiagramExtension` узнаёт блоки кода по языку и просит картинку у рисовальщика —
  интерфейс `IMdDiagramRenderer`: язык и текст на входе, картинка асинхронно на выходе.
  Рисовальщиков может быть несколько; порядок задаёт приложение.
- Пока картинка рисуется и если рисовальщик не справился, виден блок кода, как сейчас, — с текстом
  ошибки.
- Картинка кэшируется по языку и тексту; по ширине — как картинка, не шире текста.
- Копируется исходником блока. Экранный диктор называет её «Диаграмма» с языком.
- Рисовальщику передаётся светлая или тёмная тема: у mermaid, например, есть свои темы.

## Рисовальщик 1 — Kroki

- Kroki — открытый веб-сервис под лицензией MIT: принимает текст диаграммы по HTTP и отдаёт
  картинку. Знает больше 30 видов диаграмм.
- Сервер — общий kroki.io или свой: поднимается в Docker, mermaid в нём — отдельным
  образом-компаньоном.
- Форматы по видам:

  | Вид | Форматы |
  |---|---|
  | mermaid | PNG, SVG |
  | PlantUML | PNG, SVG, PDF |
  | Graphviz | PNG, SVG, JPEG, PDF |
  | Vega, Vega-Lite | PNG, SVG, PDF |
  | D2, nomnoml, Excalidraw, BPMN | только SVG |

  PNG вьюер показывает сам. SVG — только вместе с [SVG-спутником](svg-images.md).
- Наш код — около 200 строк на стандартном `HttpClient`, без чужих библиотек.
- Цена: нужна сеть, и текст диаграммы уходит на сервер. Поэтому по умолчанию выключен, а адрес
  сервера задаёт приложение.

## Рисовальщик 2 — локальный Graphviz

- Если в системе установлен Graphviz, его программа `dot` вызывается отдельным процессом и отдаёт
  PNG или SVG без сети. Только язык Graphviz.
- Наш код — около 100 строк, без чужих библиотек; путь к `dot` задаёт приложение.
- Риск: язык Graphviz умеет подтягивать локальные файлы (атрибут `image`). Для чужих документов
  это дыра: включать только для своих документов или с запретом таких атрибутов.

## Рисовальщик 3 — mermaid без сети через WebView2

- Пакет-спутник `Beresta.Markdown.Wpf.Diagrams.WebView2`.
- WebView2 — компонент Microsoft, который встраивает в программу движок браузера Edge (пакет
  `Microsoft.Web.WebView2`). Сам движок — WebView2 Runtime в варианте Evergreen — входит в
  Windows 11. На Windows 10 он стоит почти везде, но не всюду; Microsoft советует приложению
  проверять его наличие и ставить, если его нет.
- Как работает: один скрытый экземпляр браузера на приложение загружает локальную страницу с
  `mermaid.min.js` (библиотека mermaid, MIT, файл кладётся в пакет), рисует схему и отдаёт
  картинку PNG.
- Цена: первый запуск — до секунды и больше; браузер — отдельные процессы на десятки или сотни
  мегабайт памяти; `mermaid.min.js` — несколько мегабайт к пакету.
- Живой WebView2 прямо в документе не годится: тяжёлый контрол на каждый блок, а окно браузера
  поверх WPF плохо уживается с прокруткой и виртуализацией.

## Открытые вопросы

- Как получить PNG. Через холст страницы: метки mermaid в `foreignObject` делают холст
  «грязным», и его нельзя выгрузить, — нужен `htmlLabels: false`. Или снимком страницы через
  `CapturePreviewAsync`.
- Папка данных WebView2: по умолчанию она рядом с программой, а в Program Files туда не
  записать — нужна папка в профиле пользователя.
- Версия mermaid и её обновление вместе с пакетом.
- Предел размера картинки и таймаут рисования.
- Нужны ли диаграмме подпись и увеличение по щелчку.
