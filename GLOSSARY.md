# Глоссарий

| Термин | Значение |
|---|---|
| Блок | Элемент документа, который занимает строки целиком: абзац, заголовок, блок кода, цитата, список, таблица, разделитель, отступ. Цитата и пункт списка сами состоят из блоков |
| Отступ | Блок на месте пустой строки исходника между соседними блоками |
| Инлайн | Кусок текста внутри блока с одним набором начертаний — жирный, курсив, зачёркнутый, код, ссылка, — либо жёсткий перенос строки |
| Виджет | Элемент документа, который добавило расширение: блочный или строчный. Рисуется своим шаблоном, может иметь своё состояние и содержать блоки и другие виджеты |
| Состояние виджета | То, что виджет помнит помимо текста: свёрнут ли, что выбрано. Хранится у вьюера по устойчивому идентификатору и живёт дольше контрола |
| Расширение | Подключаемый набор для своего синтаксиса: настройка разбора, превращение своих узлов в модель, шаблоны своих виджетов |
| Текстовая карта | Сквозной текст документа, где каждый кусок привязан к элементу модели и к исходнику. На ней держатся выделение, копирование и поиск |
| Декорация | Подсветка диапазона текстовой карты поверх отрисовки: выделение, найденное, правки диффа |
| Поля | Колонка слева от документа с номерами строк исходника |
| Устойчивый идентификатор | Номер элемента модели, который переживает новый текст, пока элемент не изменился или изменился на своём месте |
| Неделимый элемент | Блок или инлайн без своего текста в карте — разделитель, виджет без текста: выделяется и подсвечивается только целиком |
| Провайдер стилей | Набор шаблонов, по одному на вид блока, которым вьюер рисует документ |
| Ключ темы | Ресурс оформления — шрифт, цвет, отступ, — который потребитель перекрывает у себя, чтобы поменять вид, не подменяя шаблонов |
| Своя ссылка | Ссылка, которую обрабатывает приложение, а не система; обычно со своей схемой: `codex_page:...` |
| Ссылка наружу | Ссылка, которую открывает системный обработчик: браузер, почтовый клиент |
| Цель ссылки | Адрес ссылки ровно так, как он записан в markdown, до всякого разбора |
| Потребитель | Приложение, которое подключает вьюер — пакетом или сабмодулем |
