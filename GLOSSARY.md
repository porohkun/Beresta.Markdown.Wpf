# Глоссарий

| Термин | Значение |
|---|---|
| Элемент разметки | То, что вьюер рисует по смыслу: заголовок, абзац, жирный, таблица, ссылка, плашка. У одного элемента может быть несколько записей — Markdown, HTML, синтаксис других программ — и рисуется он одинаково |
| Блок | Элемент документа, который занимает строки целиком: абзац, заголовок, блок кода, цитата, список, таблица, разделитель, отступ. Цитата и пункт списка сами состоят из блоков |
| Отступ | Блок на месте пустой строки исходника между соседними блоками |
| Инлайн | Кусок текста внутри блока с одним набором начертаний — жирный, курсив, зачёркнутый, код, ссылка, — либо жёсткий перенос строки |
| Виджет | Элемент документа, который добавило расширение: блочный или строчный. Рисуется своим шаблоном, может иметь своё состояние и содержать блоки и другие виджеты |
| Состояние виджета | То, что виджет помнит помимо текста: свёрнут ли, что выбрано. Хранится у вьюера по устойчивому идентификатору и живёт дольше контрола |
| Расширение | Подключаемый набор для своего синтаксиса: настройка разбора, превращение своих узлов в модель, шаблоны своих виджетов |
| Текстовая карта | Сквозной текст документа, где каждый кусок привязан к элементу модели и к исходнику. На ней держатся выделение, копирование и поиск |
| Пометка | Оформление куска текстовой карты или строк исходника поверх отрисовки: заливка, черта, рамка, строка во всю ширину, полоса или значок на полях. Контролов в пометке нет |
| Слой пометок | Пометки одного владельца — поиска, диффа, комментариев приложения. Слои рисуются по порядку, выделение — поверх всех |
| Поиск в ленте | Запрос на списке вьюеров: каждый созданный вьюер подсвечивает свои совпадения, без текущего совпадения и прокрутки |
| Декорация | Заливка куска текстовой карты из свойства `Decorations` вьюера — нижний слой пометок |
| Разметка выделенного | Выделенный кусок документа, заново записанный markdown со своим оформлением |
| Поля | Колонка слева от документа с номерами строк исходника |
| Пустое место | Место нужной высоты перед строкой исходника: встаёт перед самым внешним элементом, который начинается с этой строки, — блоком, пунктом, строкой таблицы, строкой текста или кода. Элементы не режутся; это не текст: не выделяется, не копируется, своего номера на полях нет |
| Панели вровень | Две панели диффа, где совпавшие строки стоят на одной высоте, а напротив изменений — пустые места |
| Своё место строки | Экранная строка, с которой начинается строка исходника: у текста и кода — их строки, у отступа — он сам, у блока без своих строк — верх его рамки. Там поля ставят номера |
| Отслеживаемое место | Кусок текстовой карты или строки исходника, которые находят своё место в новом тексте — по своему блоку и тексту вокруг. Пропадают вместе со своим блоком |
| Устойчивый идентификатор | Номер элемента модели, который переживает новый текст, пока элемент не изменился или изменился на своём месте |
| Неделимый элемент | Блок или инлайн без своего текста в карте — разделитель, виджет без текста: выделяется и подсвечивается только целиком |
| Провайдер стилей | Набор шаблонов, по одному на вид блока, которым вьюер рисует документ |
| Ключ темы | Ресурс оформления — шрифт, цвет, отступ, — который потребитель перекрывает у себя, чтобы поменять вид, не подменяя шаблонов |
| Своя ссылка | Ссылка, которую обрабатывает приложение, а не система; обычно со своей схемой: `codex_page:...` |
| Якорь | Место документа, к которому ведёт ссылка `#id`: заголовок или сноска |
| Открыватель ссылок | То, что открывает ссылку, которую не обработало приложение; стандартный отдаёт веб и почту системе |
| Загрузчик картинок | То, откуда вьюер берёт картинку по адресу из разметки; стандартный умеет веб, файлы, ресурсы приложения и `data:` |
| Ссылка наружу | Ссылка, которую открывает системный обработчик: браузер, почтовый клиент |
| Цель ссылки | Адрес ссылки ровно так, как он записан в markdown, до всякого разбора |
| Потребитель | Приложение, которое подключает вьюер — пакетом или сабмодулем |
| Плашка | Блок с видом — заметка, совет, важное, предупреждение, осторожно — и цветом, значком и заголовком этого вида; внутри любые блоки. Бывает сворачиваемой |
| Сворачиваемый блок | Блок с заголовком, содержимое которого видно, только пока блок развёрнут |
| Список определений | Термины, у каждого — одно или несколько определений под ним |
| Front matter | Служебный блок в самом начале документа между строками `---`, обычно YAML: заголовок, теги, дата. Вьюер его не рисует |
| Оформленный текст | Кусок текста с именем оформления от расширения: рисуется стилем темы по этому имени и остаётся текстом карты |
| Набор расширений | Несколько расширений, которые подключаются одним: вьюер опрашивает набор, набор — свои расширения по порядку |
| Готовое расширение | Расширение под популярный синтаксис другой программы, которое поставляется в самой библиотеке; по умолчанию выключено |
| Резолвер | То, что реализует приложение, чтобы готовые расширения узнали смысл связи: есть ли вики-страница, как зовут участника |
| Шорткод | Вставка `{{< имя аргументы >}}` или `{% имя аргументы %}` из генераторов сайтов — Hugo, Jekyll: виджет по имени, которое зарегистрировала библиотека или приложение |
| Карточка | Неделимый строчный виджет, который ведёт по адресу: карточка видео с превью, карточка-ссылка с названием и адресом. Щелчок идёт путём ссылок |
| Карточка свойств | Front matter, нарисованный таблицей «ключ — значение» |
| Потоковый текст | Текст, который приходит кусками, — ответ модели или сети. Вьюер получает накопленное пачками не чаще заданного интервала |
| Прилипшая прокрутка | Прокрутка, которая держится у края, куда приходят новые данные, пока растёт содержимое. Отлипает, если увести её от края, и прилипает снова у края |
