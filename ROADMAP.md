# Дорожная карта

Вьюер, который потребитель легко меняет визуально снаружи и дополняет своим синтаксисом, с
выделением сквозь блоки и виртуализацией. Работа идёт только по этому файлу; отложенное — в
[`BACKLOG.md`](BACKLOG.md). Термины — в [`GLOSSARY.md`](GLOSSARY.md).

## Этап 0. Второе демо — интеграционное

- [x] **Приложение для отработки встраивания и смены визуала** (рабочее имя
  `Markdig.Wpf.Viewer.Showcase`). Нынешнее демо остаётся проверкой минимального подключения.
  - [x] HandyControls той же версии, что в Storaxis (3.6.0).
  - [x] Переключатель светлой и тёмной темы через `ThemeManager.Current.ApplicationTheme`.
  - [x] Ключи `Md.*` от цветов HandyControl — механизм из Storaxis: словарь-наследник
    `ThemedResourceDictionary`, который при смене темы пересоздаётся
    (`AppThemeService.ReloadThemedDictionaries`, `Storaxis.App/Resources/MarkdownTheme.xaml`).
  - [x] Площадка для проверок следующих этапов: свои шаблоны и стили, расширения, две панели.

## Этап 1. Фундамент

Ломающие изменения публичного API — до версии 1.0.

- [x] **Иерархия инлайнов.** Вместо одной записи с флагами — общий базовый тип: текстовый кусок
  с начертаниями, перенос строки и строчные виджеты.
- [x] **Позиция в исходнике у каждой вьюмодели**: диапазон символов и строк. На ней держатся
  номера строк, копирование в markdown, две панели и будущее редактирование.
- [x] **Расширения.** Один класс на расширение: своя настройка Markdig, превращение своих узлов
  в вьюмодели (блочные и строчные) через контекст, умеющий разобрать вложенную разметку, и
  шаблоны своих вьюмоделей. Подключение — `MarkdownViewer.Extensions`. Порядок: расширения →
  встроенное → запасной путь.
- [x] **Вложенность.** Виджет может содержать блоки и другие виджеты; вложенное рисуется той же
  цепочкой шаблонов. Длинное вложенное содержимое виртуализирует та же `MdBlockPanel`.
- [x] **Шаблоны блоков.** Цепочка «расширения → провайдер». `MdStyleProvider` публичный, со
  свойством `BasedOn`: в XAML заменяется один шаблон, остальные берутся от стандартного.
- [x] **Вид инлайнов снаружи.** Стили по ключам (`Md.Strong.Style`, `Md.Emphasis.Style`,
  `Md.Link.Style`, `Md.Strike.Style`) и селектор шаблонов строчных виджетов.
- [x] **Умолчания темы от приложения.** Шрифт и цвет текста берутся у хоста, а не зашиты;
  полный список ключей — в README.

## Этап 2. Текстовая карта, выделение, декорации

- [x] **Проба на `MdTextBlock`**: подсветка диапазона и попадание мышью с переносами строк,
  кодом посреди строки и ссылками. Опора проверена: у `TextBlock` публичный
  `GetPositionFromPoint`, `TextPointer.GetCharacterRect` работает на его содержимом.
- [x] **Текстовая карта** строится по модели при каждом разборе. Виджет отдаёт в неё свой текст и
  вложенное через `IMdTextSource`; без него он неделимый.
- [x] **Слой декораций**: диапазоны карты со стилем поверх отрисовки. Выделение — одна из
  декораций; найденное и правки диффа — тоже.
- [x] **Выделение во вьюере**: пара смещений в карте, мышь с автопрокруткой, щелчок по ссылке
  против перетаскивания, `Ctrl+A` и `Ctrl+C` из карты, неделимые блоки целиком. Ввод внутри
  интерактивных виджетов выделение не перехватывает.
- [x] **`MdBlockPanel.BringIndexIntoView`** — для автопрокрутки, якорей и поиска.

## Этап 3. Позиции и прокрутка снаружи

Две панели — в том числе с разными текстами, как в диффе — синхронизирует потребитель; вьюер
даёт ему «что где» и «прокрути к».

- [ ] **Соответствие строки исходника и вертикальной позиции** в обе стороны: оценочно для
  несозданных блоков, точно для созданных.
- [ ] **Прокрутка к строке исходника** так, чтобы она встала в заданную долю видимой области
  прокрутки-предка.
- [ ] **Что сейчас видно**: строка исходника в точке привязки видимой области и уведомление о её
  смене.
- [ ] **Пример синхронизации во втором демо**: диф снаружи, якоря на неизменённых участках,
  линейная интерполяция внутри изменённых, ведущая панель — та, которую крутит пользователь.
  Правки подсвечиваются декорациями. Прижился — вынести помощник в библиотеку.

## Этап 4. Номера строк

Опирается только на позиции в исходнике из этапа 1.

- [ ] **Номера строк исходника на полях**: у блока — номер первой строки, у блока кода — каждой.
  Включаются свойством вьюера, ширина полей общая на документ.
- [ ] **Номера строк внутри блоков кода**, включаются независимо от полей.

## Этап 5. Инкрементальная пересборка

- [ ] **Неизменившиеся блоки переживают новый текст**: устойчивые идентификаторы, повторное
  использование вьюмоделей и контейнеров, сохранённые высоты. Нужна виджетам с состоянием,
  живому предпросмотру и будущему редактированию.

## Этап 6. Виджеты

- [ ] **Строчные виджеты** внутри `MdTextBlock`; в текстовой карте — символ-заместитель с
  необязательным текстом для копирования.
- [ ] **Состояние виджета вне контрола** — по устойчивому идентификатору блока.
- [ ] **Высота, меняющаяся после загрузки**, без прыжков видимого.
