# Дорожная карта

## Локализация витрины

Витрина на английском и русском: строки интерфейса, подписи вьюера, контролы HandyControl и
md-тексты. При запуске — язык системы: русская — русский, любая другая — английский.
Переключатель — рядом с темой, язык меняется на лету. Выбор между запусками не запоминается.

Строки — в `Strings.resx` (английский) и `Strings.ru.resx`; в разметке — `{loc:Text Ключ}`, привязка,
которая меняется вместе с языком и работает в шаблонах; из кода — `Localizer.Text`, о смене языка
сообщает `Localizer.Changed`. Язык меняет `Localizer.Apply`: строки витрины, русские подписи вьюера и
`ConfigHelper.Instance.SetLang` для контролов HandyControl, их переводит пакет `HandyControls.Lang.ru`.
`{hc:Localization}` из HandyControls не используется: внутри шаблонов он падает.

### Этап 1. Переключатель и основа

- [x] Язык в настройках витрины: при запуске — язык системы; переключатель EN/RU в верхней панели
  рядом с темой.
- [x] Строки витрины: `Strings.resx`, `Strings.ru.resx`, `{loc:Text Ключ}`, `Localizer`.
- [x] Подписи вьюера `Md.*` — словарь русских подписей, подключается в русском режиме и снимается в
  английском. Сейчас они вшиты в `MarkdownTheme.xaml`.
- [x] На ключах — окно: заголовок, верхняя панель, список витрин (название — ключом из модели).
- [x] Скрипт проверки: шаг выбора языка.

Проверка: переключатель меняет на лету панель, список витрин, контекстное меню вьюера и кнопки
HandyControl.

### Этап 2. Строки витрин

- [x] Шапки и настройки всех витрин — ключами.
- [x] Строки из кода — через `Localizer.Text`: группы «Своего вида» (сетка перестраивается при смене
  языка), варианты «Копирования», названия наборов и прочее. Строки с подстановкой собираются в коде.
- [x] Скрипт проверки: `tab:` ищет витрину по названию на текущем языке; шаг, который выводит
  видимый вне вьюеров текст с кириллицей.

Проверка: в английском режиме вне вьюеров нет кириллицы, нигде нет `[Ключ]`.

### Этап 3. md-тексты на двух языках

- [x] Пары файлов: `Имя.md` — английский, `Имя.ru.md` — русский; для общего образца и 14 текстов
  витрин. Русские — нынешние тексты, английские — перевод. Английские «Было» и «Стало» двух панелей
  расходятся теми же правками, что русские.
- [x] Загрузка по текущему языку с откатом на английский. Русские md остаются в основной сборке и в
  сателлит не уходят.
- [x] При смене языка витрины перечитывают тексты; правка «Предпросмотра», чат и поток начинаются
  заново.
- [x] Содержимое в коде — история чата, имена людей у резолверов, тексты потока — на двух языках;
  время сообщений чата — в формате текущего языка.

Проверка: каждая витрина в обоих языках показывает текст своего языка; переключение — на лету.

### Этап 4. Инструменты, правила, документация

- [ ] `tools/WikiShots.cs` снимает витрину в английской локализации; подмена подписей `Md.*` в нём
  больше не нужна. Снимки английской вики пересняты в английской локализации.
- [ ] `AGENTS.md` витрины: строка — ключом в обоих resx, текст — парой md; новая возможность
  вьюера попадает в оба образца.
- [ ] Английская вики называет сценарии витрины по-английски; сейчас в `Coordinates.md` —
  «Кнопки на полях» и «Две панели».
