# Частные решения

## Beresta.Markdown.Wpf

- HTML в буфере обмена повторяет экран (`MdClipboard`): картинка, которую не пустила `ImagePolicy`, — alt-текстом, ссылки — как есть; защищать программы, куда вставляют, — не задача вьюера.
- Тема по умолчанию рассчитана на стандартную светлую тему WPF; тёмную тему и высокую контрастность потребитель делает ключами — тёмные темы у всех разные.
- Клавиатуру вьюер не развивает — выделение с клавиатуры, фокус у переключателей и кнопок, рамка фокуса: работу с клавиатурой целиком поменяет будущий редактор.
- Экранный диктор (UI Automation) поддерживается: это надстройка, поведение для остальных она не меняет.
- Полная поддержка HTML — забота расширений потребителя; встроенно — только теги из списка в вики (Supported Markdown).
- Вьюер только показывает и исходник не меняет ничем, флажок задачи — картинка: редактирование придёт целиком вместе с редактором, половинчатых фич до него нет.
- Экспорт в HTML и печать — не ответственность контрола: по заявке или пул-реквесту.
