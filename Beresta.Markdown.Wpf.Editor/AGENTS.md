# Beresta.Markdown.Wpf.Editor

Второй пакет: `MarkdownEditor` — наследник вьюера, который правит исходник своего документа в
AvalonEdit. Режимы правки и их устройство — в [`docs/ideas/editor.md`](../docs/ideas/editor.md).

Общие правила кода, документации и комментариев — в [корневом `AGENTS.md`](../AGENTS.md).

## Зависимости

[`Beresta.Markdown.Wpf`](../Beresta.Markdown.Wpf/AGENTS.md) ссылкой на проект — в пакете это
зависимость от вьюера той же версии — и пакеты AvalonEdit и ReverseMarkdown. Под .NET 7 AvalonEdit
берёт сборку `net6.0-windows`, а ReverseMarkdown и его AngleSharp — `netstandard2.0`; её зависимость
`System.Text.Encoding.CodePages` проект под .NET 7 подключает сам.

## Состав

| Часть | Что это | Где |
|---|---|---|
| Редактор | контрол: вьюер, который правит исходник; текст — в документе AvalonEdit, в `Markdown` уходит с задержкой и сразу по `CommitText` | `MarkdownEditor` |
| Режимы правки | просмотр, только контролы, блоки, весь текст; front matter — полями, текстом или никак | `MdEditMode`, `MdFrontMatterEditing` |
| Версии текста | тексты, которые видел вьюер, с версиями документа: место из показанного текста — на нынешний документ | `SourceVersions` |
| Строки показанного текста | начала строк текста, который показывает вьюер | `TextLines` |
| Клавиши правки | Enter продолжает список и выходит из него, Tab и Shift+Tab сдвигают пункт, нумерованный список после них и после удаления строки пункта перенумеровывается, Ctrl+B и Ctrl+I обрамляют жирным и курсивом, ограждение кода закрывается само, вставка — только текстом, а Ctrl+Shift+V и меню исходника переводят HTML в Markdown | `EditingKeys`, `HtmlMarkdown` |
| Оформление исходника | раскраска строк AvalonEdit и фон с полосой у строк по описанию исходника вьюера; вид `X` — ключи темы `Md.X.*`, свойство без своего ключа — сеттер стиля `Md.X.Style`, плашка — кисть своего вида; из тех же ключей — поля и высоты видов для распорок | `SourceColorizer`, `SourceBackground`, `SourceLookIndex`, `LookStyle` |
| Подсветка кода | подсветчик вьюера на определениях AvalonEdit: имя цвета определения сводится к виду куска; редактор ставит его себе, если подсветчик не задан | `MdAvalonCodeHighlighter` |
| Высота и отступ строк | распорки нулевой длины доводят строку до высоты блока в отрисовке, пустую — до высоты отступа, а блок кода и таблицу — до высоты нарисованных вместе со строками, которых в отрисовке нет; маркер пункта и цитаты AvalonEdit считает пробелом — перенесённые строки начинаются под текстом | `LineStruts`, `StrutElement`, `StrutRun`, `SourceFit`, `LineMarkers`, `MarkerText` |
| Столбцы таблиц | разделитель с местом до края столбца по самой широкой ячейке; место не текст, таблица шире AvalonEdit не выравнивается | `TableColumns`, `SeparatorElement`, `SeparatorRun` |
| Поиск и замена | совпадения запроса в документе AvalonEdit — фоном в окне и пометками в отрисовке, куда их переводит текстовая карта вьюера; замена текущего и всех одним шагом отмены | `MdSourceSearch`, `SourceMatches`, `SearchBackground` |
| Тема | свои ключи `Md.Source.*` и меню исходника `Md.Source.ContextMenu`; вливается в ресурсы приложения после темы вьюера | `Themes/Generic.xaml` |
| Окно правки | AvalonEdit на холсте вместо правимых блоков: края-якоря, высота строк окна, внутренняя прокрутка к видимой части, строки для полей и координат вьюера — по тексту строк, без полей распорок | `SourceWindow` |
| Доки пакета | русский перевод XML-доков публичного API; в пакет английские доки уходят рядом со сборкой, русские — в `ru` | `Docs/` |

## Редактор — такой же потребитель вьюера

Только публичный и защищённый API вьюера: обход, понадобившийся редактору, чинится во вьюере.
