# Beresta.Markdown.Wpf.Editor

Второй пакет: `MarkdownEditor` — наследник вьюера, который правит исходник своего документа в
AvalonEdit. Режимы правки и их устройство — в [`docs/ideas/editor.md`](../docs/ideas/editor.md).

Общие правила кода, документации и комментариев — в [корневом `AGENTS.md`](../AGENTS.md).

## Зависимости

[`Beresta.Markdown.Wpf`](../Beresta.Markdown.Wpf/AGENTS.md) ссылкой на проект — в пакете это
зависимость от вьюера той же версии — и пакет AvalonEdit. Под .NET 7 AvalonEdit берёт сборку
`net6.0-windows`.

## Состав

| Часть | Что это | Где |
|---|---|---|
| Редактор | контрол: вьюер, который правит исходник; текст — в документе AvalonEdit, в `Markdown` уходит с задержкой и сразу по `CommitText` | `MarkdownEditor` |
| Режимы правки | просмотр, только контролы, блоки, весь текст; front matter — полями, текстом или никак | `MdEditMode`, `MdFrontMatterEditing` |
| Версии текста | тексты, которые видел вьюер, с версиями документа: место из показанного текста — на нынешний документ | `SourceVersions` |
| Строки показанного текста | начала строк текста, который показывает вьюер | `TextLines` |
| Клавиши правки | Enter продолжает список и выходит из него, Tab и Shift+Tab сдвигают пункт, ограждение кода закрывается само, вставка — только текстом | `EditingKeys` |
| Оформление исходника | раскраска строк AvalonEdit и фон с полосой у строк по описанию исходника вьюера; вид `X` — ключи темы `Md.X.*` | `SourceColorizer`, `SourceBackground`, `SourceLookIndex`, `LookStyle` |
| Высота и отступ строк | распорки нулевой длины поднимают строку до высоты блока в отрисовке, маркер пункта и цитаты AvalonEdit считает пробелом — перенесённые строки начинаются под текстом | `LineStruts`, `StrutElement`, `StrutRun`, `LineMarkers`, `MarkerText` |
| Столбцы таблиц | разделитель с местом до края столбца по самой широкой ячейке; место не текст, таблица шире AvalonEdit не выравнивается | `TableColumns`, `SeparatorElement`, `SeparatorRun` |
| Тема | свои ключи `Md.Source.*`; вливается в ресурсы приложения после темы вьюера | `Themes/Generic.xaml` |
| Окно правки | AvalonEdit на холсте вместо правимых блоков: края-якоря, высота строк окна, внутренняя прокрутка к видимой части, строки для полей вьюера | `SourceWindow` |
| Доки пакета | русский перевод XML-доков публичного API; в пакет английские доки уходят рядом со сборкой, русские — в `ru` | `Docs/` |

## Редактор — такой же потребитель вьюера

Только публичный и защищённый API вьюера: обход, понадобившийся редактору, чинится во вьюере.
